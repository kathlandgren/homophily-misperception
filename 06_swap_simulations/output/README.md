# Media-bias swap simulation outputs

This folder is not tracked in git: its contents are regenerated by the scripts below.

## What is here

6 compressed NumPy archives, one per (m, f_s) with N = 1000:

- **m** ∈ {2, 5, 10}
- **f_s** ∈ {2/3, 0.8}

Each holds a 6×6 grid of (h_ss, h_oo) ∈ {0.25, 0.375, …, 0.875} × ~96 swap fractions (0–20% in 0.25% steps, then 1% steps up to the minority cap), 200 simulations per condition. Arrays are indexed `[i_hoo, i_hss, i_swap]`; `all_*` is over all nodes, `peers_*` over unswapped nodes only.

`output_exclude_self/` (sibling folder) holds the same files with agents counting only their neighbours, used by `12_include_self_comparison/`.

## To regenerate from scratch

Run on a cluster as a 6-task SLURM array job (up to 8 h per task, 36 cores), from the repository root:

```bash
mkdir -p logs
sbatch 06_swap_simulations/submit_sweep_F.sh
EXCLUDE_SELF=1 sbatch 06_swap_simulations/submit_sweep_F.sh   # -> output_exclude_self/
```

Naming convention:

```
sweep_F_m{m}_fs{f_s:.4f}_N1000.npz
```
