# Broadcast node model outputs

This folder is not tracked in git: its contents are regenerated by the scripts below.

## What is here

324 NumPy archives: for each m ∈ {2, 5, 10}, f_s ∈ {0.5, 2/3, 0.8}, (h_ss, h_oo) ∈ {0.25, 0.5, 0.75}² and model ∈ {`pa`, `sbm`}, misperception after adding a broadcast source with attention share λ ∈ [0, 1] and stance μ ∈ [0, 1] (21×21 grid). Files ending `_rescaled` use the rescaled transform shown in the SI. `baseline_source` records whether the peer baseline was exact or interpolated.

## To regenerate from scratch

Pure numpy; runs locally in seconds once `06_swap_simulations/output/`, `10_degree_matched/output/` and `10_degree_matched/output_G3x3/` exist:

```bash
python 11_broadcast_media/run_sweep_G.py
```

Naming convention:

```
sweep_G_m{m}_fs{0500|0667|0800}_hss{h*1000}_hoo{h*1000}_{pa|sbm}[_rescaled].npz
```
