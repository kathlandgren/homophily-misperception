# Degree-matched simulation outputs

This folder is not tracked in git: its contents are regenerated by the scripts below.

## What is here

27 compressed NumPy archives, one per (m, f_s, N):

- **m** ∈ {2, 5, 10}
- **f_s** ∈ {0.5, 2/3, 0.8}
- **N** ∈ {100, 500, 1000}

Each holds 11×11 grids over (h_ss, h_oo) ∈ {0, 0.1, …, 1}² for the preferential attachment model (`pa_*`) and the degree-matched stochastic block model (`sbm_*`), 200 simulations per grid point per model, plus the matched `H_out`. Arrays are indexed `[i_hoo, i_hss]`.

Two sibling folders:

- `output_G3x3/`: 9 files on the 3×3 grid h ∈ {0.25, 0.5, 0.75}, N = 1000, the exact peer baselines for the broadcast model (`11_broadcast_media/`). Without them, `run_sweep_G.py` interpolates the 11×11 grid and prints a warning.
- `output_exclude_self/`: the main grid with agents counting only their neighbours, used by `12_include_self_comparison/`.

## To regenerate from scratch

Run on a cluster as SLURM array jobs, from the repository root:

```bash
mkdir -p logs
sbatch 10_degree_matched/submit_sweep_E.sh                     # 27 tasks, up to 8 h each, 32 cores
sbatch 10_degree_matched/submit_sweep_E_G3x3.sh                # 9 tasks  -> output_G3x3/
EXCLUDE_SELF=1 sbatch 10_degree_matched/submit_sweep_E.sh      # -> output_exclude_self/
```

Naming convention:

```
sweep_E_m{m}_fs{f_s:.4f}_N{N}.npz
```
