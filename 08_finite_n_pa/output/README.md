# Finite-N preferential attachment simulation outputs

This folder is not tracked in git: its contents are regenerated by the scripts below.

## What is here

513 compressed NumPy archives: 27 (m, f_s, N) combinations × 19 rescaling variants.

- **m** ∈ {2, 5, 10}
- **f_s** ∈ {0.5, 2/3, 0.8}
- **N** ∈ {100, 500, 1000}
- **variant**: `none` (no rescaling), `peragent_d{δ}_g{γ}` and `groupmean_d{δ}_g{γ}` for δ ∈ {0.5, 1, 2}, γ ∈ {0.25, 0.5, 0.75}

Each file stores 21×21 grids over (h_ss, h_oo) ∈ [0, 1]² of the mean and variance of β_s, β_o and β_overall across 200 simulations, indexed `[i_hoo, i_hss]`.

`output_exclude_self/` (sibling folder) holds the same files with agents counting only their neighbours, used by `12_include_self_comparison/`.

## To regenerate from scratch

Run on a cluster as a 27-task SLURM array job (up to 8 h per task, 8 cores; the N = 1000 tasks with m = 5 or 10 take longest), from the repository root:

```bash
mkdir -p logs
sbatch 08_finite_n_pa/submit_sweep_D.sh
EXCLUDE_SELF=1 sbatch 08_finite_n_pa/submit_sweep_D.sh   # -> output_exclude_self/
```

Naming convention:

```
sweep_D_m{m}_fs{f_s:.4f}_N{N}_{variant}.npz
```
