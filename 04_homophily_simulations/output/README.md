# Baseline homophily simulation outputs

This folder is not tracked in git: its contents are regenerated by the scripts below.

## What is here

Pickle files written by `run_simulations.py`, one per combination of homophily ∈ {0, 0.25, 0.5, 0.75, 1}, m ∈ {2, 5} and N ∈ {1000, 10000}. `compute_summary_statistics.ipynb` summarizes them into `../summary_stats/`.

## To regenerate from scratch

```bash
python 04_homophily_simulations/run_simulations.py
```

Uses 50 `ProcessPoolExecutor` workers; about 30–60 min on a multi-core machine.
