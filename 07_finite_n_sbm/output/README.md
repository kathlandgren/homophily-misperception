# Finite-N stochastic block model simulation outputs

This folder is not tracked in git: its contents are regenerated by the scripts below.

## What is here

513 compressed NumPy archives: 27 (H_out, f_s, N) combinations × 19 rescaling variants.

- **H_out** ∈ {0.1, 0.3, 0.5}
- **f_s** ∈ {0.5, 2/3, 0.8}
- **N** ∈ {100, 500, 1000}
- **variant**: `none` (no rescaling), `peragent_d{δ}_g{γ}` and `groupmean_d{δ}_g{γ}` for δ ∈ {0.5, 1, 2}, γ ∈ {0.25, 0.5, 0.75}

Each file stores 21×21 grids over (H_in^s, H_in^o) ∈ [0, 1]² of the mean and variance of β_s, β_o and β_overall across 200 simulations, indexed `[i_hino, i_hins]`.

`output_exclude_self/` (sibling folder) holds the same files with agents counting only their neighbours, used by `12_include_self_comparison/`.

## To regenerate from scratch

Run on a cluster as a 27-task SLURM array job (up to 2 h per task, 8 cores), from the repository root:

```bash
mkdir -p logs
sbatch 07_finite_n_sbm/submit_sweep_C.sh
EXCLUDE_SELF=1 sbatch 07_finite_n_sbm/submit_sweep_C.sh   # -> output_exclude_self/
```

Naming convention:

```
sweep_C_hout{H_out:.2f}_fs{f_s:.4f}_N{N}_{variant}.npz
```
