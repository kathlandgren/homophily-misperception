# Mean-field outputs

This folder is not tracked in git: its contents are regenerated by the scripts below.

## What is here

36 compressed NumPy archives of the large-N mean-field misperception on 101×101 grids:

- 33 files `sweep_A_hout{H_out:.2f}_fs{f_s:.4f}.npz`: stochastic block model, H_out ∈ {0, 0.1, …, 1}, f_s ∈ {0.5, 2/3, 0.8}
- 3 files `sweep_B_fs{f_s:.4f}.npz`: preferential attachment model, f_s ∈ {0.5, 2/3, 0.8}

## To regenerate from scratch

Both run locally in about a minute:

```bash
python 09_mean_field_sensitivity/run_sweep_A.py
python 09_mean_field_sensitivity/run_sweep_B.py
```
